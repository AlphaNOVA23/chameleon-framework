========================================
  CHAMELEON FRAMEWORK — STARTUP GUIDE
========================================

For the deployed dashboard test, use Terminals 1, 2, and 5. Terminals 3 and 4 are for local development.


TERMINAL 1: Cowrie Honeypot (Docker)
------------------------------------------------
docker run -d --name chameleon-honeypot -e COWRIE_HONEYPOT_LOGTYPE=plain -p 22:2222 -v "C:\Users\tanma\cowrie_logs:/cowrie/cowrie-git/var/log/cowrie" cowrie/cowrie:latest

  → Maps attacker-facing host port 22 to Cowrie's container port 2222
  → Uses plain JSON logging to avoid Cowrie's failing rotating-file handler
  → Must be running FIRST — everything else reads its logs


TERMINAL 2: Sensor Agent (for the deployed Render backend)
------------------------------------------------
cd /d D:\Code\FYP\chameleon-framework
python backend\sensor\chameleon-agent.py --token CHAM_SENS_01_KEY --server https://chameleon-backend-fm38.onrender.com --logfile C:\Users\tanma\cowrie_logs\cowrie.json

  → Tails only new events and posts Cowrie JSON events to the deployed backend
  → Successful connect, command, and close events are printed here


TERMINAL 3: Local Backend (optional; for local frontend development)
------------------------------------------------
cd d:\Code\FYP\chameleon-framework\backend
python main.py

  → Runs on http://localhost:8000
  → Tails cowrie.json for events
  → Broadcasts to dashboard via WebSocket


TERMINAL 4: Frontend (React + Vite Dev Server)
------------------------------------------------
cd d:\Code\FYP\chameleon-framework\frontend
npm run dev

  → Runs on http://localhost:5173
  → Open this URL in your browser


TERMINAL 5: SSH Attack Tests
------------------------------------------------
cd /d D:\Code\FYP\chameleon-framework

  Automated bot over one SSH session (host port 22):
    python backend\test_ssh_bot.py 22

  Manual human-style SSH session (host port 22):
    ssh root@localhost
    → Enter any password when prompted, then type commands with natural pauses
    → Type exit to close; the session should move to Forensics Archive
